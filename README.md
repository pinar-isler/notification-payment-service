# Notification & Payment Service 🚀

Bu proje; e-posta (SendGrid), SMS (NetGSM) bildirimlerini ve ödeme altyapısını (Iyzico) yönetmek üzere **Go (Golang)** dili ile geliştirilmiş bir mikroservis / API mimarisidir.

---

## 🛠️ Teknolojiler ve Araçlar

* **Dil:** Go (Golang)
* **Web Framework:** Gin / Standard HTTP
* **E-Posta Servisi:** SendGrid API
* **SMS Servisi:** NetGSM API
* **Ödeme Entegrasyonu:** Iyzico API (Sandbox / Test)
